# System Intelligence

An AI-powered system intelligence engine that builds and maintains
a living model of complex systems.

It analyzes interconnected data, detects emerging risks, investigates
incidents, and maintains persistent memory of historical findings.

## Core Capabilities

- Relationship Mapping: Build an interconnected graph of system entities,
  events, dependencies, and changes.
- Risk Detection: Identify potentially dangerous interactions and
  emerging anomalies.
- Incident Investigation: Correlate evidence and investigate competing
  explanations for failures.
- Persistent Memory: Maintain compact records of incidents, findings,
  and verified solutions.

## Initial Demonstration

The first implementation focuses on a simulated payment-processing
microservice architecture.

It will demonstrate how individually reasonable changes can combine
to create unexpected system-wide failures.

## Architecture

- Backend: Python, FastAPI
- AI: Meta Model API
- Graph Engine: NetworkX
- Database: SQLite
- Frontend: React, TypeScript
- Visualization: React Flow
- Simulation: Deterministic Python simulation engine
